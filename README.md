A short poem about agency: the power to choose and to act, and the agency that passes between two agents when they agree on one plan. Written for make.fun's "The poem about two agents agreeing" bounty.

## Run it

```sh
python3 main.py
```

It writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when unset).
